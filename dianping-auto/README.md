# 大众点评免费抽自动报名

固定启动：[start-dianping.bat](../start-dianping.bat)。只读检查：[check-dianping.bat](../check-dianping.bat)。详细说明：[使用教程.md](使用教程.md)。

程序处理「查看全部」列表中所有有“免费抽 / 免费抽奖”按钮的活动，包含普通活动，不再以橙V或会员徽标作为报名条件。已删除徽标匹配模块和模板，也不再依赖 NumPy。

默认不限报名数量、滚动次数；直到列表停止变化、出现异常或按 Ctrl+C 停止。可用 --limit 10 限制为最多成功报名 10 项。

每成功报名一项，返回列表后固定执行一次上滑，使内容上移一个活动卡片的高度，再处理下一项。距离优先按相邻活动标题间距计算，无法测量时按本机约 335 像素；松手前停顿，减少惯性多滚。达到报名数量上限的最后一项也会执行这一步。

输入复用本机 scrcpy 4.1 的 UHID 通道，页面读取使用 build/ui-dump.jar。Pillow 仅用于核验点击区域和底部导航，不做会员筛选。BAT/CMD 为 ASCII 无 BOM、CRLF；Python 与日志为 UTF-8。

程序排除顶部工具栏和底部导航覆盖的按钮，点击前重新读取坐标并核对橙色按钮区域。误入带底部导航的“我的”页面时，尝试点击左侧“免费试”返回；已识别的分享/更多菜单会先关闭。恢复最多 3 次，提交结果不明确时不重复提交。

日志在 logs/运行时间/events.jsonl。当前设备为小米 9 SE，保持竖屏、三键导航、已解锁。scrcpy 安装目录为 %LOCALAPPDATA%\Microsoft\WinGet\Packages\Genymobile.scrcpy_Microsoft.Winget.Source_8wekyb3d8bbwe\scrcpy-win64-v4.1。

“橙V专享免费试”仅是从评友中心进入综合列表的一个入口名称，不限制活动类别。
