# 大众点评免费抽自动报名

固定启动：[start-dianping.bat](../start-dianping.bat)。只读检查：[check-dianping.bat](../check-dianping.bat)。详细说明：[使用教程.md](使用教程.md)。

程序处理「查看全部」列表中所有有“免费抽 / 免费抽奖”按钮的活动，包含普通活动，仅提前排除能读取到明确“Lv6–8专享”标注的活动，其余普通和会员活动正常处理。已删除徽标匹配模块和模板，也不再依赖 NumPy。

默认不限报名数量、滚动次数；直到列表停止变化、出现异常或按 Ctrl+C 停止。可用 --limit 10 限制为最多成功报名 10 项。

每成功报名一项，返回列表后固定执行一次上滑，使内容上移一个活动卡片的高度，再处理下一项。距离优先按相邻活动标题间距计算，无法测量时按本机约 335 像素；松手前停顿，减少惯性多滚。达到报名数量上限的最后一项也会执行这一步。

输入复用本机 scrcpy 4.1 的 UHID 通道，页面读取使用 build/ui-dump.jar。Pillow 仅用于核验点击区域和底部导航，不做会员筛选。BAT/CMD 为 ASCII 无 BOM、CRLF；Python 与日志为 UTF-8。

程序排除顶部工具栏和底部导航覆盖的按钮，点击前重新读取坐标并核对橙色按钮区域。误入带底部导航的“我的”页面时，尝试点击左侧“免费试”返回；已识别的分享/更多菜单会先关闭。导航恢复最多 3 次。

报名失败或等待结果超时后，先检查是否已经成功，再关闭失败弹窗、返回列表并重新打开同一活动。重新读取到“我要报名”后才再次提交，每项最多提交 3 次。仍失败则记录并跳过，继续其他活动；已结束、资格不足或找不到原活动入口也会跳过，不计为成功。无法恢复的未知页面、断线、验证码和频率限制仍会停止。

日志在 logs/运行时间/events.jsonl。当前设备为小米 9 SE，保持竖屏、三键导航、已解锁。scrcpy 安装目录为 %LOCALAPPDATA%\Microsoft\WinGet\Packages\Genymobile.scrcpy_Microsoft.Winget.Source_8wekyb3d8bbwe\scrcpy-win64-v4.1。

“橙V专享免费试”仅是从评友中心进入综合列表的一个入口名称，不限制活动类别。

## Lv5 资格与重试（2026-09-13 更新）

列表仅排除明确可读取的 Lv6–8 专享标注（兼容大小写、空格、全角及不同连接号），不根据橙V徽标或没有写明的等级要求猜测。若限制只在图片中、无法读取，仍会进入活动，由报名提示核验。

报名提示等级不足、不符合资格或仅限 Lv6–8 时，记录并返回列表，本轮不再尝试该活动。网络/提交失败及确认弹窗未打开时，返回重新核验、重开同一活动，最多尝试 3 次；已成功则不重复提交，达到次数上限后跳过并继续。重启程序会重新判断资格。

资格不足弹窗关闭方式：识别‘你暂未满足报名要求’后，优先点击弹窗内‘我知道了’（包括无文字标签的图片按钮），必要时点击弹窗右上方的‘×’。确认弹窗消失后才返回活动列表；弹窗存在时不使用手机导航返回键。2026-09-13 已在‘淮扬春·伍’当前弹窗实测关闭并返回列表。
