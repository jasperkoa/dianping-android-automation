# 大众点评免费抽：使用教程

## 启动

1. USB 连接并解锁小米 9 SE，打开大众点评。
2. 进入免费试的“查看全部”列表。可通过「评友中心 → 橙V专享免费试 → 查看全部」进入，也可直接从免费试入口进入。入口名称不影响报名范围。
3. 双击 D:\Android\Mi9SE\start-dianping.bat。

**所有普通活动和会员活动都参与，只要求存在可识别的“免费抽 / 免费抽奖”按钮。** 已报名、已结束或没有该按钮的项目会跳过。0 元领、兑换、付费项目不属于本脚本的免费抽流程。

脚本可以从评友中心的免费试栏目自动进入“查看全部”；如果入口被工具栏遮住，会提示先手动进入，避免误点顶部菜单。

## 默认数量与停止

默认不限报名数量与滚动次数，持续处理当前列表，直到列表不再变化或遇到无法恢复的异常。并不保证平台全部活动都已报名；无法识别的页面或活动需要手动检查。

运行时不要操作手机，不要切换到后台。保持竖屏和三键导航。投屏可以开着观看，电脑鼠标不被占用。

停止：点击程序终端窗口，按 Ctrl+C。若询问是否终止批处理，输入 Y 回车。不要同时打开多个报名窗口。

## 限制每次的数量

右键 start-dianping.bat → 编辑，修改以下数字：

```bat
set "LIMIT=0"
set "MAX_SCROLLS=0"
```

0 表示不限。LIMIT 是最多成功报名数，MAX_SCROLLS 是最多滚动次数。例如 LIMIT=10 即最多成功报名 10 项。

也可临时指定：

```powershell
& 'D:\Android\Mi9SE\start-dianping.bat' --limit 1 --max-scrolls 5
```

BAT 保持 ASCII 无 BOM、Windows CRLF 换行。不要往 BAT 添加中文提示；程序中文输出已统一为 UTF-8。

## 运行过程

免费抽 → 我要报名 → 确认报名 → 核验“报名成功” → 返回列表 → **页面上移一个活动卡片** → 重新读取排序 → 继续。

成功后必定执行一次单活动上滑，不等待当前屏幕的活动全部处理完。滑动距离按相邻活动标题的间距计算，无法识别间距时使用本机约 335 像素；松手前停顿以减少惯性。日志会显示“报名后上移一个活动”。列表到底时实际可移动距离可能不足一个活动。

顶部菜单区、底部导航区以及被遮挡的按钮不参与点击。点击前重新核对按钮坐标及屏幕颜色。误入“我的”时，程序尝试点击左侧“免费试”回到列表，并保留本次已处理记录；列表若被 App 重置，会重新扫描，跳过已处理项目。误开可识别的分享/更多菜单时会先关闭。

最多自动恢复 3 次；同一活动连续 3 次定位失败时停止。提交后未确认成功会停止，不自动重复提交。

程序沿用弹窗当前协议与候补状态，不切换候补、不使用 PASS 卡。需要验证码、遇到频率限制或未知弹窗时手动处理。

注意：更多菜单通过再次点击右上角菜单按钮关闭，不使用会离开页面的系统返回键。菜单关闭后继续读取列表；若回到了评友中心，会重新选择免费试入口并进入“查看全部”。

## 检查和日志

双击 D:\Android\Mi9SE\check-dianping.bat，只读检查，不点击、不报名。候选为空可能是当前屏幕没有露出的可报名按钮，可向下滚动后再查。

日志：D:\Android\Mi9SE\dianping-auto\logs\运行时间\events.jsonl。

- 报名成功：该项已核验成功。
- success：本次核验成功数量。
- 重新定位：旧坐标失效，取消点击并重新识别。
- 返回底部免费试页签：正在从误入页面恢复。
- 列表停止变化：没有检测到滚动后的内容变化；可手动滚动后再启动。
- Exit code: 0：正常结束，不代表全部活动已报名。
- Exit code: 1：出现错误，查看上方中文原因。

## 本机依赖

保留整个 dianping-auto 文件夹。使用本机 Python 3.11、Pillow、ADB、scrcpy 4.1 和附带的 build/ui-dump.jar，不需要安装手机 APK。NumPy 和橙V徽标模板已不再使用。

手机黑屏或锁屏时先解锁。找不到 scrcpy server 时需检查 scrcpy 是否升级或移动。脚本针对本机 1080×2340 竖屏与三键导航布局，切换全面屏手势后需要重新适配。
